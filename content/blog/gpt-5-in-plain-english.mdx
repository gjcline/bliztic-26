# GPT-5, in plain English

## What it is

OpenAI's new flagship model. It replaces GPT-4o as the default in ChatGPT and adds "built-in thinking," i.e., it decides when to take extra time to reason and when to respond fast. Plus users get higher usage; Pro adds **GPT-5 Pro** for even longer, deeper reasoning. API access is available across the GPT-5 family.

## Why it matters

- Smarter, steadier answers across coding, math, writing, health, and vision-based tasks.
- Bigger context (up to ~400k tokens) so you can drop in long docs, logs, or transcripts without chunking.
- Agent-ready: stronger tool use and long multi-step execution for "do the task" workflows.

## The models (pick by cost/latency vs depth)

- **gpt-5** — Best general model for complex reasoning, long context, and agent chains. Use for assistants, RAG with long documents, analytics, and coding copilots.
- **gpt-5-mini** — Faster and cheaper. Great for well-defined tasks, high-volume routing, classification, light generation, and function calling.
- **gpt-5-nano** — Smallest, for ultra-low latency and cost-sensitive micro-tasks. Think re-ranking, field extraction, guardrails.
- **GPT-5 Pro (ChatGPT plan)** — A ChatGPT Pro tier feature that dials up extended reasoning for harder questions. It's a product plan, not a separate API SKU.

## How it "thinks"

GPT-5 is a unified system that automatically applies extra reasoning when the prompt benefits from it; you can also explicitly ask for deeper thinking in ChatGPT. For developers, the API exposes the usual messages/tools interface plus larger context and improved structured outputs for multi-step agents.

## Safety upgrades (headline items)

- Safe-completion training focuses on giving the most helpful safe answer instead of default refusals.
- Preparedness for bio-risk and dual-use: tighter safeguards as capability rises.

## Where it shines for businesses

- Search + summarize your knowledge base with 400k-token context, then route actions via tools.
- Agentic ops: triage emails, draft replies, update CRM, file tickets, schedule, then report back.
- Analytics copilots: ingest raw logs or spreadsheets, ask questions, generate charts and SQL, create briefs.
- Coding acceleration: refactors, bug hunts, end-to-end scaffolding for internal tools.

## Quick start menu

- **ChatGPT:** It's the default. Type normally; add "think hard about this" when you want extra reasoning. Pro users can select "GPT-5 Thinking."
- **API:** Use `gpt-5` for complex flows; switch to `gpt-5-mini` or `gpt-5-nano` in high-volume steps to cut cost. Check the Models page and pricing before you scale.

## Deployment tips

- Tier your pipeline: heavy steps on gpt-5, bulk steps on mini/nano.
- Exploit long context: keep the whole spec or call log in-session for fewer hallucinations.
- Lean on tools: function calling + structured outputs make agents reliable and auditable.

## Availability

GPT-5 is live in ChatGPT for Free, Plus, Pro, Team, Enterprise, and Edu (with tiered usage). Enterprise and Edu get broader rollout the following week.
